# daybook

A quiet space for journaling and keeping track of everyday tasks. The app is built with React, TypeScript, and Vite.

## Run locally

- `npm install` installs project dependencies.
- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run lint` runs Oxlint.

## Features

- Switch between Journal and To-do list from the sidebar.
- Create journal entries and add, complete, or remove tasks.
- Entries and tasks persist in the browser using local storage.
